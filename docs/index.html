WHAT IT DOES

审查能力，围绕一种合同类型打磨

不做万能合同助手，只做中文货物采购合同：规则、法条、评测与界面都围绕这一场景。

01 / AGENTS

多 Agent 并行

商务条款、违约解除、争议合规三个审查员同时工作；规则引擎作为确定性的第四条分支。

02 / RULES + LLM

规则 + LLM 双轨

25 条规则保召回，LLM 补语义与上下文；字段缺失时规则跳过而不是误报。

03 / RAG

混合检索

BM25（jieba）+ 百炼 text-embedding-v3 + RRF 融合；法条按「条」切块，可选 DashScope rerank。

04 / GATES

引用与证据门禁

模型只能引用法条 ID，正文由后端渲染；合同证据必须逐字定位，否则降级为「需人工确认」。

05 / HITL

图内人工复核

LangGraph interrupt + AsyncSqliteSaver；暂停任务跨后端重启仍可继续决策。

06 / EXPORT

修订稿与报告

已采纳建议自动落地为新合同文本，导出 DOCX + 变更清单；报告支持 MD / JSON / DOCX。

PIPELINE

从上传到可导出的报告

每个节点写入进度事件并持久化到 SQLite；前端轮询渲染 Agent 时间线。

  1. 上传合同
  2. 解析 / 切条款
  3. 规则 + 3 Agent 并行
  4. 合并去重
  5. 修改建议
  6. 证据 / 引用门禁
  7. 人工复核
  8. 报告 / 修订稿

GET STARTED

几分钟跑起来

mock 模式不需要 API Key；桌面版内置后端与示例数据，可离线体验。

# 后端（mock 模式）
cd backend && uv sync
uv run uvicorn app.main:app --reload --port 8000

# 前端
cd frontend && npm install
npm run dev

打开 localhost:5173； 或构建前端后单端口启动。完整环境、Docker、桌面端、live 模式与测试见 QUICKSTART。
